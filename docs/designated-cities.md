# 政令指定都市の利用案内（2026-09-10）

`/cities` と `/cities/{slug}` に全20都市・40施設の選定を追加。新しい詳細ガイド35件と既存の地域ガイド5件を参照する。全国の内訳はグランピング7、ソロ6、アクティビティ7、岩盤浴7、ヒーリング7、スパ6。都市ごとに6ジャンルが揃ったことを意味しない。

対象都市の根拠は指定都市市長会 https://www.siteitosi.jp/about/designated.html 。東京の特別区は政令指定都市に含めない。

## データと出典

- `app/Support/designated-cities.json`: 都市と施設キーの明示的な対応。住所の部分一致で市所属を推測しない。
- `app/Support/city-guide.json`: 公式運営者・自治体・公的観光機関で確認した情報。各レコードに確認日と出典URLを保存。
- 近郊は阿賀野市、南丹市、呉市の3件。都市ページで市内の37件と別セクションに表示する。
- 変動料金・確認できなかった総額は数値で推測しない。料金の合算は内訳・対象日・利用範囲を併記。
- 秋ヶ瀬は宿泊不可の日帰り区画。ヒーリングの一部は庭園・植物園散策であり施術サービスではない。
- 新しい写真・レビュー・評価・緯度経度は生成していない。編集情報と訪問体験記を区別する。

## 取り込みと検証

公開時は既存の地域ガイド取り込み後に `CityGuideSeeder` を実行する。既存施設には編集キーだけを付け、本文・予約リンク・評価・体験記を保持。同じ取り込みを繰り返しても件数は増えない。名称や公式URLで複数候補がある場合はトランザクションを中止する。

`CityGuideTest` は20都市の応答、40施設のリンク・出典、JSON-LDと表示一覧の一致、市内と近郊の区別、未定義都市の404、既存投稿の保持、繰返し取り込みを検証する。サイトマップに20都市と全国一覧を含める。
