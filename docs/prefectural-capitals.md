# 県庁所在地への拡張（2026-09-10）

47都道府県の県庁所在地と既存20政令指定都市の和集合を掲載する。重複15都市を除き52エリア。東京都は都庁所在地の新宿区を対象とし、東京全域を区内として扱わない。既存の政令指定都市の詳細ガイドと市外の近郊候補は維持する。

Google Places (New) で新規32都市×6ジャンルの192検索を実施し、すべて応答を確認した。市外の結果も含まれるため、公式サイト・運営者・公的案内から所在地と利用内容を独立に照合した45施設を `app/Support/capital-facilities.json` に収録。既存施設は同一都道府県の名称または正規化した公式URLで照合し、二重登録を防ぐ。既存の投稿・住所・紹介・予約URLは上書きしない。

公開するのは独立に確認した名称、所在地、ジャンル、短い紹介、公式URL、出典、確認日。Google由来の口コミ・評価・写真・座標を保存しない。検索記録に残すのはplace IDと独自の検索条件のみ。APIキーは実行時の環境変数で受け取り、リポジトリやページに含めない。調査スクリプトは52都市×6ジャンルの312検索に対応し、1実行は最大120件に制限する。

全市で6ジャンルが揃うという表示はしない。都市一覧・ジャンル別件数は実際に表示する詳細ガイドと施設から計算する。全国の全登録施設数とは別の件数であり、近郊候補を含む。各施設には既存の投稿導線があるが、体験記を生成したり訪問済みと扱ったりしない。

確認時の注意点：
- 華のゆ秋田は2026年10月からの長期休業案内があるため今回の追加対象から除外。
- Googleの所在地検索で現れた市外施設（那覇検索の瀬長島など）は採用しない。
- テルマー湯新宿店の岩盤浴は男女別、姫若子の湯の岩盤浴は女性専用。
- ASOBI PARKは大人1人だけの入場不可。ソロ利用できる施設として扱わない。
- コトリの湯の所在地とカーナビ推奨の経由地を混同しない。
- 料金の異なる記載や過去のお知らせが混在する場合、確定できない金額は転記しない。

`CapitalFacilitiesTest` は全52ページの実施設表示、47都道府県の対応、サイトマップ、JSON-LDと画面・件数の一致、ジャンル内リンク、重複ID、確認日・出典・投稿導線、繰り返し投入と既存投稿保持を検証する。公開時に `CapitalFacilitiesSeeder` を実行する。
