# 東京・大阪・名古屋の区別案内

2026-09-10。東京23区、大阪市24区、名古屋市16区の63区に対応。
`/wards/{metro}` は全区の件数、`/wards/{metro}/{ward}` は区内施設・ジャンル別件数・詳細と体験記へのリンクを表示する。

`WardGuide::locate()` は都道府県を照合したうえで住所の先頭から区を判定する。大阪・名古屋は市名を必須とし、堺市北区や別の市の港区を混ぜない。住所中の施設名に区名が出るだけでは所属区としない。区が不明な施設を座標や名称から推測して追加しない。郵便番号、空白、全角英数は判定用に正規化する。

既存の施設を使用し、区ページ作成のための複製や体験記の生成は行わない。住所のない既存施設でも公式照合カタログの同一施設があれば、その所在地を表示用に使用する。データベース上の住所や投稿は変更しない。

掲載0件の区は未掲載と表示し、他区の一覧と施設登録への導線を用意する。空ページはnoindex,followとし、サイトマップには実施設が掲載された区のみ含める。登録が増えれば件数・一覧・サイトマップも更新される。63区全てに実施設が揃ったという意味ではない。

区名の出典は各都市の一覧ページに明記。区一覧・施設リスト・BreadcrumbListをJSON-LDで出力し、既存の都市ガイドや施設詳細から相互リンクする。
